Grounding: a stale-warning path once injected an unverified day count (14), collapsing nightly grounded_answers. The checker now keeps warnings number-free. Scores on this page update only after the next nightly with that fix deployed.

Forecasts: backtests show LSTM/XGBoost rarely beat repeating last week on these series — so the product leads with persistence, not the losing model.
